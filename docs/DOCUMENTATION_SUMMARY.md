## Current positioning

The documentation deliberately emphasizes that the project is:

- evidence-first
- deterministic
- Git-based
- focused on dependency and history analysis

It does not describe a finished web product, a production dashboard, or a complete AI inference stack.

## Maintainer guidance

When updating the repo, keep docs aligned with these truths:

- Git and dependency evidence are implemented.
- AI decision reasoning is a future phase.
- project maturity is early-stage and MVP-focused.
