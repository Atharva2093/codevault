How it works

CausalCode constructs a deterministic memory layer for software repositories by extracting structural evidence directly from Git commit logs and dependency manifest files (such as requirements.txt, pyproject.toml, and package.json).

AI models (such as Gemma) only explain collected evidence and must cite specific commits or file changes. All AI assertions are strictly bounded to empirical repository data.

Static import analysis detects file-level module references across the codebase at HEAD. Because static analysis cannot execute code, it cannot prove dynamic runtime execution or configuration-only dependency usage.
